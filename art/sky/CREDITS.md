# Sky textures

Used by `shaders/sky.gdshader` (set up in `scripts/world/day_night_cycle.gd`).

| File | Source |
|---|---|
| `moon.png` | Near side of the Moon, baked by `tools/bake_sky.py` from the LRO colour map `lroc_color_poles_1k.jpg` of NASA's CGI Moon Kit (NASA's Scientific Visualization Studio, https://svs.gsfc.nasa.gov/4720). NASA imagery is not copyrighted and may be used commercially (NASA media usage guidelines); no endorsement by NASA is implied. The downloaded map is kept in `src/`. |
| `transmittance.exr`, `multiscatter.exr`, `sky_irradiance.exr` | Atmosphere look-up tables computed by `tools/bake_sky.py` (after S. Hillaire, "A Scalable and Production Ready Sky and Atmosphere Rendering Technique", 2020). No downloads. |
| `cloud_shape.png`, `cloud_detail.png`, `cloud_weather.png`, `blue_noise.png` | Tileable Perlin, Worley and blue noise generated by `tools/bake_sky.py`. No downloads. |

Rebuild everything (and re-download the Moon map if `src/` is missing) with
`python3 tools/bake_sky.py` (needs numpy and Pillow), then `godot --headless --import`.
